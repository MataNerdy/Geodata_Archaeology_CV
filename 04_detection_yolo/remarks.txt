Developed object detection pipeline for archaeological structures (kurgans) using YOLOv8 on multimodal remote sensing data (LiDAR + aerial imagery).

• Built custom dataset pipeline from geospatial data (raster + polygons → bounding boxes)
• Performed iterative dataset refinement (noise filtering, class balancing)
• Improved minority class detection (mAP50: 0.07 → 0.15)
• Achieved overall mAP50 ≈ 0.20 on a highly challenging small-object detection task
• Analyzed precision–recall trade-offs and model behavior via PR/F1 curves

Задача

Детекция курганов (kurgans detection)

Модальности: LiDAR + Aerial (Li + Ae)

Классы:
    - kurgany_tselye
    - kurgany_povrezhdennye

Модель: YOLOv8 (detect)

Данные

v2 (baseline)

    images: 635
    boxes: 4288

    проблемы:
    - много шумных bbox
    - дисбаланс классов
    - переобучение на легкие патчи

    recall высокий
    precision низкий

v3 (clean)

    images: 313
    boxes: 539

    Фильтры:

    - частичная фильтрация edge-объектов
    - MIN_VALID_FRACTION
    - MIN_CONTRAST
    - ограничение плотных тайлов (MAX_OBJECTS)
    - downsampling negative

    precision вырос
    recall упал

v4 (balance)

    images: 347
    boxes: 772

    баланс:
    povrezhdennye: 430
    tselye:        342

Модель

    YOLOv8s
    imgsz = 1024
    epochs = 80 (early stop v3 ~71)

Ключевые наблюдения

1. Основной прирост качества достигнут не архитектурой,
а переработкой датасета

2. Чистка данных увеличивает precision
но ухудшает recall

3. v2 → high recall, low precision
v4 → balanced precision, lower recall

4. модель лучше учится на чистых данных, чем на больших

5. Основная сложность задачи:
    - маленькие объекты
    - низкий контраст
    - частично разрушенные структуры

6. Модель начала различать классы, а не просто находить "что-то"

Главный вывод
    Aggressive dataset cleaning improved precisionbut reduced recall due to removal of difficult samples.Preserving challenging examples is criticalfor small-object detection in remote sensing.

Ограничения

    - сильная зависимость от качества тайлинга
